# 经验回流草稿：How X-Rays Are Made（竖屏 8-bit 科普片，65 秒，14 场，60 fps，原子级机制）

这份草稿按 skill 的回流要求写：做对了的事（做法＋证据＋为什么＋何时用），新坑（现象＋原因＋修法＋怎么查）。
没有直接改 skill 目录，整合时归到 `07-正面经验.md`、`风格配方/14_8bit` 和对应 reference 的「踩过的坑」。

### [正面] 原子级几场共用一个「世界」，相机在里面推、拉、横移
- 做法：S05–S08 共用一张钨晶格（`lib/tungsten.js`）：电子到达表面 → 推到原子 A 看轫致辐射 → 拉远看很多次掠过 → 横移到原子 B 看内层电离 → 快速拉远穿过发热的晶格。每场的相机都从上一场的终点出发。
- 证据：四场之间没有一次换图，相机连续；镜头表里的「横移」「拉远」都是真的在同一世界里移动。
- 何时用：同一尺度下要讲好几个机制时；先搭世界，再给每场写相机。

### [正面] 关键一瞬给单个粒子自己的时钟（子弹时间）
- 做法：轫致辐射光子发出那一刻，只让那颗电子和它的光子的时钟降到 0.25×，0.6 秒后恢复；其他粒子和镜头照常。配乐同一时刻做一次低通下潜再回来。
- 证据：第一版光子 0.4 秒就飞出画面，标签打不完；加了子弹时间后光子、标签、能量表（80 → 49 keV、光子 31 keV）都看得清。
- 为什么：光速是电子速度的两倍，物理上不能把光子画慢；把整颗粒子的时钟放慢，速度比例不变，仍然对。

### [正面] 用几何算出来的 X 光片，而不是画出来的
- 做法：手的每根骨头是空心管（皮质＋髓腔），软组织是手指圆柱＋手掌板；每个像素沿射线积分衰减，再加一点钝化掩模（数字 X 光片本来就做边缘增强），按窗宽窗位映射到灰阶。
- 证据：皮质边缘自然最亮、关节间隙自然出现，和真片一致；同一套几何同时给出剖面（S10/S11）里每个光子的命运和探测器上的透射曲线。

### [正面] 竖屏里的数据流改成纵向
- 现象：探测器第一版横着摆，读出芯片和数字一直在画外，最后一秒才甩过去。
- 修法：改成从上到下：X 射线 → 闪烁体 → 光电二极管 → 开关 → 数据线 → 芯片 → 数字往下流，镜头顺着往下接到下一场的像素网格。
- 何时用：竖屏解说里任何「流程」都优先纵向排。

### [坑] 世界单位的线宽在极端推近时变成一整条色带
- 现象：S04→S05 推近到 260 px/mm 时，阳极表面出现一条 150 px 宽的灰带，玻璃壳描边也变成粗块。
- 原因：`lineWidth` 用的是毫米（0.6 mm），推近 260 倍就是 156 px。
- 修法：描边、高光线一律 `1.2 / z`（屏幕像素恒定），纹理块尺寸用 `min(物理尺寸, 3 / z)`。
- 怎么查：在最深的推近帧单独出静帧看，不要只看整片缩略图。

### [坑] 半透明辉光被量化成无关颜色
- 现象：橙色热辉光叠在灰色金属上，量化后出现粉色（调色板里有软组织粉）。
- 修法：写「只提亮」的抖动辉光 `FX.glowL`：按距离取本色阶里的颜色，只覆盖比它暗的像素；辉光永远落在自己的色阶上。
- 何时用：调色板里有多个相近色族时，所有光晕都用这种方式。

### [坑] 有序抖动的阈值差了 0.5：强度为 0 时也涂一半像素
- 现象：S08 开头热度还是 0，晶格背景却整片发灰发红；所有光晕外圈都有一层 50% 的暗色网点。
- 原因：写成了 `floor(强度×色数 + Bayer − 0.5)`，Bayer 取 0..1，强度 0 时一半像素落到第 0 档。
- 修法：`floor(强度×色数 + Bayer) − 1`，小于 0 不画；强度 0.3 正好 30% 像素取第 0 档。
- 怎么查：把效果强度调到 0 出一帧，画面应该和不加效果完全一样。

### [坑] 场与场之间的「切」要逐对查，不只看缩略图
- 做法：`tools/video_diffs.py` 读成片（按 ffprobe 的帧率），列出整屏变化超 60% 的帧和孤立尖峰；每个落在场边界的尖峰都出两侧各一帧对照。
- 证据：查出 6 处跳：房间墙面一帧变黑、灯丝颜色按阈值跳档、晶格相机对不上、原子 B 换样子＋能谱框消失、准直器一帧消失、房间一帧出现在 X 光片四周；分别用溶解、连续 RGB 插值、相机接续、保持外观并淡出、镜头先移过准直器、先只露片子再淡入房间修好。
- 60 fps 下慢速平移每隔几帧整屏移 1 像素，会被列成大量 5% 左右的「孤立尖峰」；这是像素画的整数步进，不是跳变。

### [坑] 有限的晶格在快速拉远时露出边界
- 修法：拉远的终点缩放要在晶格填满画面的范围内，溶解到下一个尺度（焦点 → 阳极盘）要在露边之前做完。

### [坑] 电子先被路过的另一个原子偏转
- 现象：要掠过原子 A 的电子沿着原子行入射，先擦过前一个原子，路径早早弯掉。
- 修法：`TW.approach` 在若干入射角里找一条 100 px 内离其他原子核都 ≥15 px 的通道，只用目标原子算力。

### [qa 判读] 文字检查会报世界坐标里的招牌字
- `tools/text_check.py` 把房间墙上的 X-RAY 灯牌（画在世界里的字）在镜头移动时出画、或从标题黑底下面经过也报出来；这类是预期的，不是字幕问题。真正的字幕冲突（14 处）都改到 0。
