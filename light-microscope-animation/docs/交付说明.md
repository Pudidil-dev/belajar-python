## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 交付范围：客户要的是可编辑工程，自己渲染。这里的成片只是验证用（检查渲染命令能跑通、过门禁），放在 `build/`，不进仓库、不交付。
- 用了哪个语法 / 风格：没用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg）。
  - 共享部分：像素工具包和合成器内核沿用本仓库离心机、注射器两集。
  - 新写部分：显微镜 3D 模型、光线追踪器、X 光讲解、视野、字幕、配乐、音效。
  - 画风：16-bit 像素「实验室游戏」。270×480 画布，4 倍最近邻放大；粗剪影，1px 描边，4–8 级色阶加 Bayer 抖动；字幕用 5×7 像素字体。
  - 三种景别各有一套美术：
    - 微距：玻片和血滴；
    - 全景：白色显微镜三分之四视角，用小型光线追踪器渲成 16-bit 预渲染精灵；
    - 显微：染色涂片的圆形目镜视野，按 Beer-Lambert 吸光度成像，再有序抖动。
  - 色板：本仓库 `navy` 加血红、伊红粉、偏红的梅紫（色相约 307°，不在蓝紫禁区）。
