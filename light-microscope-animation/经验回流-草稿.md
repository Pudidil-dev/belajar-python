# 经验回流（草稿）：What One Drop of Blood Looks Like Under a Microscope

给 skill 维护者看的候选条目，没有改动 skill 本身。

1. **要一台认得出的机器、还要多个景别时，自写一个小光线追踪器很划算**：
   - 用 numpy 按像素求交（凸多面体、圆柱、圆台、椭球，再加 A 减 B 打孔），每帧约 0.5 秒；
   - 按色阶上色、加 Bayer 抖动，外轮廓 1px 深色描边，部件之间画暗一档的内线，看起来就是 16-bit 预渲染精灵；
   - 镜头随便推拉摇，近了细节自然多出来（「每个景别揭开新细节」）；
   - 同一个模型换成正交侧视，就是 X 光讲解的底图。
2. **对焦只改清晰度、不改放大**：显微视野不画颜色，先算染料的光密度（OD），对焦就是模糊 OD，再过 Beer-Lambert 成像，最后有序抖动。模糊的圆盘原地变清楚，中央淡区自然出现，不用缩放去假装。
3. **平移视野要整像素**：视野中心按整像素取整，抖动图案跟着同一个整数偏移走，细胞就整块平移，不闪。
4. **光路讲解按真实的近轴薄透镜追迹画**：集光镜让光变平行，聚光镜会聚到标本，物镜在镜筒里成倒立实像（细胞上的紫点换边，倒立看得出来），目镜在焦距内当放大镜用。在折光棱镜处用「斜接点」接上折线，光线在拐角不会跳。
5. **循环靠形状匹配、而且要「动着切」**：最后一帧是目镜圆，大小和位置正好等于开场血滴。缩放曲线用 1−cos(πu/2)，到切点还在动。先前版本提前 0.5 秒缩完，最后 15 帧一模一样，就是冻帧。
6. **字幕在镜头变焦之后、按像素网格合成**：字一直是 1:1 的像素，不会跟着画面放大；开头半秒不放字，钩子保持是一个场景（lint 的④条）。
7. **客户中途加讲解**：先查资料核对光学事实，再把讲解段拆成 2–4 秒的分步镜（lint 的⑥条不许一镜超过 8 秒），配乐按同样的步点加小节，总长跟着改，并在交付时说清楚。
