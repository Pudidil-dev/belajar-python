- 用了哪个语法 / 风格：没用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg）。
  - 共享部分：像素工具包 `engine/gfx.py` 和合成器内核，沿用本仓库前几集。
  - 新写部分：
    - 以毫米为单位的世界加 2D 相机，每个尺度都重新画，所以推近会显出新细节；
    - 葡萄、圆底烧瓶、电热套、蒸馏头加温度计、直形冷凝管（外观和剖面）、接收瓶、液珠和液滴；
    - 13 小节配乐和音效；
    - 精灵图导出 `--sprites` 和渲染配置 `render.json`。
  - 画风：8-bit RPG 实验室像素风。
    - 270×480 画布，4 倍最近邻放大到 1080×1920。
    - 粗剪影，1px 阶梯描边，有限色板，只用一种棋盘抖动。
    - 没有渐变，没有 3D 镜头环绕。
  - 三种景别各有一套美术，见 `assets/sprites/_sheet.png`：
    - 全景，约 1 px/mm；
    - 近景，2.2–4.7 px/mm：温度计刻度、磨口、沸石、气泡；
    - 剖面，10–13 px/mm：剖开的玻璃壁、夹套里的水、内管里的蒸汽点、壁上的液珠。
  - 色板（每种颜色只有一个用途）：
    - 深海军蓝底；
    - 深葡萄紫，偏红，色相约 308°，不在蓝紫禁区；
    - 紫罗兰只用在葡萄高光上，镜头表写了允许蓝紫的理由；
    - 青色只给冷却水；
    - 白边只给透明液滴和玻璃高光；
    - 琥珀色只给热量提示。
- 客户 brief 对照：

    - 葡萄的近景，一开始就在晃，高光扫过；

  - 微镜头 B（12–14s）：整根冷凝管的剖面。
    - 水从靠近接收瓶的下口进，往上流，从靠近烧瓶的上口出；
    - 蒸汽在内管里往下走；
    - 玻璃壁一直看得见。
