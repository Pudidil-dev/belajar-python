## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 交付范围：客户要的是可编辑工程、精灵图、原创音频和渲染配置。上面过门禁的是 `python render.py --preview` 的预览（540×960），和成片是同一套帧，只是放大 2 倍而不是 4 倍；预览放在 `build/`，不进仓库。成片（1080×1920）客户可以自己用 `python render.py` 渲到 `out/grape-juice-distillation.mp4`；这一版客户要求在会话里直接渲染并发给他。
- 用了哪个语法 / 风格：没用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg）。
  - 以毫米为单位的世界加 2D 相机，每个尺度都重新画，推近会显出新细节；加热套另有 x 光层（`engine/heater.py`）。
  - 画风：8-bit RPG 实验室像素风。270×480 画布，4 倍最近邻放大；粗剪影、1px 阶梯描边、有限色板、一种棋盘抖动。
  - 游戏手感：挤压拉伸、零件按拍子落位、整像素滚动的相机、撞击时的屏幕抖动、环境动画按 15 步/秒走（on twos）。
- 修改记录（第二版）：
  1. 加上下文字幕。中途客户又改了两次：先说字太大、要小字、跟着物体、不要在上面；再说字幕要干净。最终做法：
     - 5×7 像素字，1 倍大小，白字加 1px 深色描边，没有底框、没有关键词上色；
     - 每条字幕挂在它解释的物体旁边，跟着物体和镜头走（葡萄、液柱、跳起来的烧瓶、加热丝、往下滑的液滴）；
     - 字幕快速打字出现，时间到就消失；字离物体稍远时，用一条细引线指过去；
     - 时间压缩时，右上角有一个小的 ▶▶ 标记。
  2. 加热器讲解：新增 x 光切片段（7–12.5s）。
     - 扫描线把加热套从上往下剖开：外壳、保温层、玻璃纤维加热碗、碗里之字形的电阻丝、拨盘后面的调节器、电线、电源线；
     - 拨盘「咔」一声打开，黄色电流点从电源线经调节器流进电阻丝，电阻丝从暗红变橙；
     - 琥珀色热弧从热碗穿过玻璃进入果汁；时间跳跃后开始沸腾，弹出一个「!」；
     - 字幕：HEATER X-RAY、WIRE COIL、ELECTRIC CURRENT、COIL GETS HOT、HEAT INTO JUICE、NO FLAME!、BOILING!。
  3. 循环改成「水滴变成葡萄」：最后推近下一颗悬挂的水滴，到葡萄的位置和大小后，用有序抖动（Bayer）做透明度渐变，31–32s 水滴变成葡萄。末帧和首帧 97.7% 的像素相同（平均差 0.9/255），最后两帧仍在变（0.68/255），不冻帧。
  4. 动作更好玩、更像 8-bit RPG：
     - 烧瓶先蹲一下，跳上加热套，落地压扁，扬起两团灰；
     - 蒸馏头、冷凝管和铁架、接收瓶按拍子依次落位，每个配一声「咔」和一个音高 blip；
     - 冷却水从下口灌进夹套；
     - 撞击时整像素抖屏，沸腾时弹「!」；
     - 第一滴馏出液配 item-get 小号角和闪光；
     - 相机快起步、小过冲、整像素滚动。
