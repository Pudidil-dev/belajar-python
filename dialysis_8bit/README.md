# How Dialysis Machines Clean Your Blood — 8-bit explainer

A 54-second, 9:16 (1080×1920, 60 fps) pixel-art motion-graphics film about hemodialysis. It has no
narration, only a synthesized score with synced sound effects. Everything is generated by code: no
image or audio assets.

Made with the [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) skill workflow:

1. shot list (`镜头表.md`, storyboard lint: yellow only, reasons noted in the file)
2. three composition directions for the opening frame (`方向/`). Direction **C, macro access**, was picked.
3. own renderer (open tier)
4. film gate
5. independent review (`审片/`)
6. `deliver.py`

## Look

- Native canvas 270×480, scaled ×4 with nearest-neighbour (pixel blocks line up with the 4:2:0 chroma
  blocks, so edges stay sharp after H.264).
- Palette: the skill's flat `navy` set (#0D1B2A ground, #5CC8E0 cyan, #F2A93B amber) plus the brief's
  colour code: blood red, dialysate blue, urea yellow, water light blue, albumin purple, pale membrane.
  No blue-purple gradient grounds.
- Kurzgesagt-style grammar in pixel form:
  - two-tone facets with same-hue outlines
  - scale travel: pull-out reveal, push-through with a colour match, lens reveal into the fiber, fast pull-out back
  - callouts that type in with a leader line
- Everything is re-rasterised through the camera every frame, so zooms stay crisp.

## Files

| file | what |
|---|---|
| `pal.py`, `pixfont.py`, `px.py`, `ui.py` | palette, hand-made bitmap fonts, pixel primitives + camera, callouts/captions |
| `world_arm.py`, `world_a.py` | arm, fistula needles, blood lines, roller pump, dialyzer, drip chamber, machine |
| `world_b.py` | dialyzer cutaway: hollow fibers, counter-current flow arrows |
| `world_f.py` | single fiber + membrane: scripted urea diffusion, red-cell/albumin bounces, ultrafiltration water, counter-current urea gradient |
| `timeline.py` | shot schedule, cameras, transitions, labels, montage, title, loop, audio event list |
| `audio.py` | 120 BPM score (27 bars = 54 s, loops) + SFX placed from `timeline.events()` |
| `render.py` | stills, contact sheets, full render to MP4 |
| `directions.py` | the three opening-frame directions |

## Render

Needs Python 3, numpy, Pillow, scipy and ffmpeg.

```sh
python3 audio.py build/score.wav                       # ~35 s
python3 render.py --out build/film.mp4 --audio build/score.wav   # ~90 s on 4 cores
python3 render.py --sheet --out build/sheet.png        # 1 frame per second contact sheet
python3 render.py --stills 0.5,16.3,52.5 --out build/stills
```

Every particle and camera move is a pure function of time. Any frame renders on its own, two renders
are identical, and each audio tick lands on the frame where its molecule crosses the membrane.
