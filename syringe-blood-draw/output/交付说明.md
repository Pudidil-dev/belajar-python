## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 用了哪个语法 / 风格：本片没有用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg）。像素工具包和合成器内核沿用本仓库离心机那一集，场景、注射器、手臂、配乐、音效都是为本片写的。
  - 画风：16-bit 像素「复古科学游戏」。270×480 画布，4 倍最近邻放大；粗剪影，1px 描边，3–8 级色阶加 Bayer 抖动；全片侧视。
  - 色板：本仓库 `navy`（平涂深海军蓝，色相约 210°，不在蓝紫禁区）加血红和一个肤色。表皮细胞、细胞核都从肤色色阶里取，没有加新颜色。
  - 注射器：在自身轴坐标里逐像素着色，可以任意角度画（竖立、摆动、30° 飞行和进针都是同一个着色器）。有透明针筒、刻度、黑色胶塞、半透明推杆、指托、按柄、绿色针座、斜面朝上的细钢针。针画成剖面，看得见针管里的血往上走。
  - 手臂：侧面剖开。表皮逐个细胞画出来，下面是带脂肪细胞的软组织、一根厚壁静脉（里面流着红细胞），再下面是深层软组织。没有加别的解剖结构，静脉是唯一的红色管子。
  - 红细胞：沿用离心机那一集的双凹盘点云打光精灵。
