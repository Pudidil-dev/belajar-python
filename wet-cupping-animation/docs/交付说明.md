## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 交付范围：可编辑工程（代码、渲染配置 `render.json`、精灵图、原创音频）和 README 里的安装、预览、渲染命令。
  - 客户明确说「不要渲染成片，我自己渲」，所以没有渲成片。
  - 上面过门禁的是 `python render.py --preview` 的预览（540×960）：和成片同一套帧，只是放大 2 倍而不是 4 倍。预览放在 `build/`，不进仓库。
  - 成片命令是 `python render.py`，输出 `out/wet-cupping-animation.mp4`（相对本工程目录）。
  - 为了确认全尺寸管线能跑，渲了一段 2 秒切片：1080×1920、H.264、30fps、48kHz 立体声 AAC，含配乐合成约 12 秒。确认后已删除。
  - Python 3.9 下重渲两帧，逐像素与 3.13 相同；配乐响度也相同（−14.01 LUFS）。
- 用了哪个语法 / 风格：没用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg）。
  - 2.5D 斜视平板相机（`engine/view.py`）：仰角从 90°（俯视）到 0°（侧视），正交投影。每一行算出它落在皮肤平面上的 y（顶面用）和在剖面上的高度（剖面用），所以顶面和剖面都能按像素用平面纹理画，任意角度都行。
  - 切割平面：下倾时从近边切进来，回升时退回去，露出 x 光式剖面。
  - 皮肤隆起：顶面是平滑的穹顶，向下按 exp(z/7mm) 衰减；剖面每个像素用牛顿法精确反解回未变形深度，所以各层按物理关系被拉伸。
  - 每个尺度重新画：俯视和斜俯视 1–4 px/mm，剖面 5，毛细血管 18–26，血液微距 52。
  - 循环做在世界里：第二组穴位在脊柱下方 240 mm，椎骨间距 24 mm 正好整除 240，背部图案按这个周期重复，所以末帧对位到第二组穴位时和首帧几乎相同。
  - 画风：客户指定的 8-bit 像素医疗动画。270×480 画布，4 倍最近邻放大；粗剪影、1px 阶梯描边、有限色板、棋盘抖动，没有渐变和 3D 模型。
- 客户 brief 对照：
  - 0–4s 俯视开场：针笔在四个穴位各点一下（TIK），每下留三个小开口；杯子依次落位；气泵软管扣到主杯阀门上（CLICK）。✓
  - 4–7s 抽气：PUMP、PUMP、PUMP、WHOOSH，杯里的空气点从软管排出，皮肤每下抬高一级；然后镜头转到侧视。✓
  - 7–13s 侧剖：
    - 剖开的杯、表皮、真皮、浅层血管，x 光式剖面；
    - 穹顶隆起，推近毛细血管，红细胞在袢里流动，组织被拉伸；
    - 血从小开口渗出；LOW PRESSURE 字幕；
    - 血管始终在皮肤里，没有被拉出来。✓
  - 13–18s 汇集：快进（▶▶），血珠沿穹顶滚到杯沿汇成一圈；镜头跟进杯里，红细胞微距；SOFT WHOOSH → BLOOP → BLOOP（第三下在微距里）。字幕只写 RED BLOOD CELLS，不说「毒素」「脏血」。✓
  - 18–21s 取杯：开阀 PSSSH，空气回流，穹顶回落；捏住杯子，POP，密封打开；杯子垂直上提、保持水平，血留在杯里；镜头跟随。✓
  - 21–24s 斜俯视：紫红色圆印和几滴残血；纱布擦两下（SWIPE），印子留下。✓
  - 24–26s 循环：
    - 拉远，三个杯子还在、一个印子；
    - 沿脊柱滑到下一组干净穴位，构图和开场一样，针笔再次进来。
    - 印子和杯子是随镜头移出画面的，没有在画面里消失。✓
  - 循环规则：没有淡入淡出、冻帧、跳变；首尾角度一致；音乐最后一小节（C7 和通鼓过门）接回第一小节，回声和混响尾巴折回开头，无缝。✓
  - 科学口径：

- 本次会话的修正（在交付前的检查里发现的）：
  1. 剖面深度反解有 bug：`tissue._z0` 原来用两步不动点迭代，穹顶高于 7 mm（λ）时发散。
     - 结果：画出来的角质层约 3 mm 厚，毛细血管袢偏深约 3 mm，和按正向公式放置的红细胞、血珠、字幕锚点对不上。
     - 改法：牛顿法精确反解，从 min(Z, 0) 出发，那一侧函数单调且凸，不会越过根。和正向公式互逆，误差约 1e-15 mm，每帧约 10 ms。
  2. CAPILLARY 的引线原来落在表皮里。原因是锚点按「主穴位 + 0.6 + 2.4k」算，而血管袢其实在世界坐标 0.6 + 2.4k 上。改为指向离它最近那条袢的顶部。
  3. 背部远端：低角度沿脊柱看过去时，远处露出一个方块「颈部」和一列桌布棋盘格，形状很怪（约 21.3–21.7s）。
     - 改法：背部一直伸到 y = 270 mm 的一条直边，边外不画，露出深蓝底。
     - 顶面的最低仰角阈值从 1.7° 降到 0.26°，接近侧视时只会出现或消失几个像素高的一条。
     - 试过把直边放到 430 mm：边进画面更晚、扫得太快，门禁把 6.75–7.0s 和 21.08–21.33s 都量成了切点，所以退回 270 mm。
  4. 抽气那一小节：鼓、贝斯、旋律原来和三下 PUMP 同拍，WHOOSH 也压在鼓和回声下面。按频段比，PUMP 在它最响的两个频段只比音乐高 −6 到 +7 dB。
     - 改法：stop-time。挤压的拍子上乐队休止，两下之间回应；WHOOSH 期间只有效果声；最后用小军鼓接进下倾。
     - 现在 PUMP 和 WHOOSH 在各自最响的两个频段比音乐高约 19 dB 以上，响度不变（−14.01 LUFS）。
