## Notes

- **One causal chain:** capsule → release → absorption → blood → tissue → the growing bacterium → wall precursors
  (Mur ligases → MraY: Lipid I → MurG: Lipid II → MurJ: flip → glycosyltransferase: strand growth → carrier
  recycling) → PBP transpeptidation (serine acyl-enzyme, D-Ala released, acceptor amine, cross-link) → amoxicillin
  binds the same PBP, the serine opens its beta-lactam ring (covalent, long-lived acyl-enzyme) → donor cannot react →
  new strands stay unlinked → remodeling hydrolases keep cutting → local weakness → turgor bulge → lysis.
- **Kept honest without words:** glycan polymerization and cross-linking are separate steps done by different
  enzymes; the drug only blocks the transpeptidase step; it never cuts wall bonds, never pushes the membrane, never
  crosses the membrane, never glows or homes in (it drifts and diffuses); lysis is a tear and an outflow, never an
  explosion.
- **The loop:** the hook's bursting cell is the *next* bacterium — the camera reaches it at 56–60 s on the same
  clockwise orbit at the same angular speed, its bulge still growing; nothing is repaired, reversed, faded or cut.
- **Mix low** for a later voiceover; exports: Cinematic (music + SFX), No_Music (SFX only), No_SFX, Silent, stems.
