# 经验回流草稿：How Quantum Computers Work（竖屏 8-bit 科普片，120 秒，11 场，60 fps，量子计算）

这份草稿按 skill 的回流要求写：做对了的事（做法＋证据＋为什么＋何时用），新坑（现象＋原因＋修法＋怎么查）。
没有直接改 skill 目录，整合时归到 `07-正面经验.md`、`风格配方/14_8bit` 和对应 reference 的「踩过的坑」。

### [正面] 量子图形全部由态矢量驱动，门做成连续的分数幂
- 做法：`lib/qm.js` 存复振幅；门在进行中是 U^s（H^s = 绕 (x+z)/√2 转 πs × 全局相位 e^{iπs/2}，CNOT(s) = I + (e^{iπs} − 1)P），
  Bloch 矢量、振幅柱（高 = |振幅|，表盘 = 相位）、两比特的四根联合柱、约化 Bloch 矢量（偏迹）都从同一组数读出。
- 证据：门结束时屏上的数正好是课本值（(|0⟩+|1⟩)/√2、(|0⟩−|1⟩)/√2、|1⟩、(|00⟩+|11⟩)/√2）；Z 门只让 |1⟩ 的相位表盘转半圈、柱高不变；
  CNOT 时两个约化矢量自然缩到球心，不用手调。
- 为什么：观众看到的每一个动作都对应一次真实的矩阵运算，「不要暗示比特在快速切换」「不能超光速传信息」这类规则自动满足。
- 何时用：任何讲量子态、相位、干涉的片子；先写态，再画图。

### [正面] 物理过程先算后放：薛定谔方程一次解完，按帧回放
- 做法：S04 的隧穿波包在加载时用分步傅里叶法解一维含时薛定谔方程（1024 点，ħ = m = 1，长度用屏幕像素，两端吸收），存 60 fps 的帧；
  亮度 = |ψ|，条纹 = Re ψ 的波峰，反射/隧穿百分比是两侧 |ψ|² 的积分。
- 证据：画面里条纹以群速度的一半滑动、势垒里振幅指数衰减、另一侧出来约五分之一，这些都不是手画的。
- 何时用：波、扩散、轨道这类有方程的现象；算一次的成本（这里 < 1 秒）远小于手调动画的返工。

### [正面] Bloch 球按每个门选视角，门与门之间让镜头绕球转
- 做法：H（从 |0⟩ 出发）在 az ≈ −0.3 侧看，Z 门（赤道上转半圈）在 az ≈ π − 0.35 看，第二个 H 在 az ≈ 3.62 看；仰角 0.62 俯视赤道。
  门之间用 1.6 秒的环绕把视角转过去，门进行时视角基本不动。
- 证据：第一版视角跟着时间匀速转，Z 门转到一半矢量正对镜头、缩成一个点；改后每次旋转都是侧面看，轨迹清楚。
- 何时用：任何 3D 矢量旋转；先算旋转平面，再把视线放在它的法线附近（略带倾角）。

### [正面] 测量链做成一个可滚动的高世界
- 做法：S09 把芯片（底部）、放大器链（中段，按 15 mK / 4 K / 300 K 分层）、数字化仪和结果面板（顶部）排在一条纵向世界里，镜头跟着信号往上爬。
- 证据：读出脉冲 → 谐振腔 → 量子极限放大器 → HEMT → 室温放大 → IQ 云 → 0/1 → 直方图，一个镜头讲完，没有一次硬切。
- 坑：第一版放大器链的世界坐标和芯片段重叠，链上的线和标签画在芯片上面；世界要先分好不重叠的高度带。

### [坑] 只提亮的辉光在比它亮的底色上失效
- 现象：S10 数据比特的紫色光晕看不见。
- 原因：`FX.glowL` 只覆盖比辉光色暗的像素；p0（#1c0c33）比地平面的 b0（#0b1830）还暗，整圈 p0 一个像素也画不上。
- 修法：色阶从比底色亮的那一档开始（['p1', 'p2']），再加一个实心菱形标记。
- 怎么查：比较色阶第一档和底色的亮度（0.3R + 0.59G + 0.11B）。

### [坑] 非整数像素间距的晶格出现摩尔纹
- 现象：S04、S05 的晶格出现大块蓝色棋盘斑。
- 原因：离子间距 4.3 px、3.2 px，取整后每隔几列多一像素，形成拍频。
- 修法：停留的镜头把缩放选在间距为整数像素的值（ZJ = 4/a、ZP = 3/a、S03 结尾 16/a）；放大镜气泡里保持固定倍率，不在里面缩放。

### [坑] 透明离屏层上的抖动辉光不显示
- 现象：S07→S08 的旧叠加层滑出时，球尖光晕消失。
- 原因：`glowL` 只写 RGB，透明层的 alpha 仍是 0。
- 修法：写像素时同时把 alpha 置 255。

### [坑] 位图文字不跟随画布平移
- 现象：S07 干涉图卡片整体平移时，矩形跟着走，字和箭头不走（或走两次）。
- 原因：`PIX.text`、`PIX.bline`、箭头头部内部会 `setTransform(1,0,0,1,0,0)`，只认屏幕坐标；`PIX.rect` 却受当前变换影响。
- 修法：卡片内不用 `translate`，所有元素显式加偏移。

### [坑] 波包看起来像一团发光球
- 现象：λ ≈ 105 px、σ = 50 px 时波包里只有一两条条纹，像一团紫色胶囊，正是简报禁止的「发光粒子」。
- 修法：λ 缩到 40 px（包里 5 条波峰），势垒高度改成 1.25 E 让 15 px 薄势垒仍有可见的指数衰减（κd ≈ 1.2，隧穿约 22%），
  亮度用 |ψ| 而不是 |ψ|²，让透射波看得见。

### [坑] 场与场的交接：把上一场的「外观」导出给下一场淡出
- 做法：每场导出自己结尾的叠加层（`S07.overlay`、`S08.overlay`、`S09.overlay`）和硬件外观（`S08.decor`、`S10.markers`），
  下一场开头先原样画出、再滑出或淡出；芯片统一用 `FR.chipView` 带封装画，避免一场有封装、一场没有。
- 证据：逐个场边界出 T−1/60 和 T 两帧对照，99 s 和 116 s 两处的暗角、外框、标记跳变都修到看不出。

### [qa 判读] 文字检查会报滚动和滑入时的瞬时重叠
- 叠加层滑入滑出、测量链从标题下方滚过时会有 1–3 帧重叠，这是运动中的交叠，不是字幕冲突；持续多帧的三处（温度读数压住 T、
  约化球的 |1⟩ 和说明行、谐振卡片标题和 7 GHz）都已改开。

### [门禁判读] 暗底上的小图形动作，门禁的「快动帧」量不出来
- 现象：48–78 s（能级、叠加、干涉）门禁报 0 快动帧、37 秒无事件，但画面里一直有东西在动：矢量旋转、脉冲、卡片、绕球环绕。
- 原因：film_gate 的快动按 12 fps、320 宽灰度整帧平均绝对差 ≥ 9 算；近黑底上几十像素宽的紫色矢量、细线、小卡片，整帧平均差到不了 9。
- 做法：真正需要的地方加整屏的镜头动作（这里是推进 Bloch 球 → 近距离绕一圈 → 拉回），其余的黄灯在交付说明里按时间码说明
  「读图段落镜头停住」；不为了过灯把读数学的镜头改成乱动。

### [qa 判读] 超过 2 秒的平滑滚动会被 qa.py 记成一串跳变
- S09 沿放大器链往上滚 3 秒，qa.py 记 82 处跳变（它只把 2 秒以内单调平滑的推拉横移算镜头事件）；用 `tools/frame_diffs.py`
  出帧差曲线，是一个 9 → 22 → 5% 的平滑钟形，没有孤立尖峰，交付说明里写清楚即可。

### [坑] qa.py 的内联依赖会装最新 Playwright，和装好的 Chromium 对不上
- 现象：`uv run qa.py` 报 `chrome-headless-shell` 不存在。
- 修法：`uv run --no-project --with playwright==1.56.0 --with numpy --with pillow python qa.py …`（直接用 python 跑，绕过脚本头的依赖声明）。
