# 经验回流（草稿）：How Blood Centrifuges Separate Blood

给 skill 维护者看的候选条目，没有改动 skill 本身。

1. **纯 Python 像素管线也能过门禁，而且用户自己渲染更省事。** numpy + Pillow 在 270×480 上画，4 倍最近邻放大；ffmpeg 用 `imageio-ffmpeg` 自带的二进制，用户只需要 `pip install` 三个包，不用装浏览器。24 秒、720 帧，4 核大约 45 秒（音频约 10 秒）。门禁绿灯：快动帧 0.31，蓝紫 0。
2. **一件反复出现的主物，用「逐像素着色器」画，而不是贴图。** 每个像素按物体局部坐标判材质，同一支试管从 1.1 倍特写一路缩到 10px 宽插进转子孔，任何缩放和角度都清晰，分层状态也只是一个参数。
3. **竖屏推进机器小窗口时，目标点要选窗口里「竖着的运动」。** 9:16 的画面比扁椭圆窗口高。往窗口中心或前缘推，画面会露出盖子的白边，中心还是转子轴；改推到转圈的侧边，那里的模糊条带是竖的，正好接进竖着的管内视图。
4. **推拉在输出分辨率上放大像素网格**（输出像素 → 画布坐标取整），推到 7–16 倍也是干净的大像素，不必为每个景别各画一套。
5. **沉降写成闭式公式**：所有细胞共用一个位移 D(t)，每个细胞有自己的六角堆积槽位；按行把槽位和起点从左到右配对，轨迹不会交叉。血浆前沿往下走、压积层往上长、两者相遇，都是这个公式自然出来的；任意一帧可以单独渲，结果确定。
6. **声音跟画面同一张时间表**（`engine/timeline.py`）。磁带停转跟转子刹车同步，堆积时的「叮」量化到十六分音符、用五声音阶，再分段量响度：第一版音效比音乐低 7 dB，调到大致持平，加速段电机领先。
7. **真峰的坑**：高通过的白噪声「咔哒」接近奈奎斯特频率，采样峰在 −1.7 dB 时，真峰还能到 +0.2 dBTP。修法是母带先做 15.5 kHz 低通，限幅之后量一次真峰，超了就再压一次。
