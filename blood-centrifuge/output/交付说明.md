## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 用了哪个语法 / 风格：本片没有用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg），用户自己渲染时不需要浏览器。
  画风是 16-bit 像素游戏（SNES 时代），在 `14_8bit` 卡的做法上升了一档：
  - 270×480 画布，4 倍最近邻放大到 1080×1920；
  - 每种材质 5–9 级色阶，用 Bayer 4×4 抖动做渐变，部件有 1px 深色描边；
  - 玻璃半透明用 SNES 色彩数学，淡出用主亮度 16 级；
  - 推拉在输出分辨率上放大整张像素网格，不模糊、不重采样。
  色板是本仓库 `ink`（炭黑底、暖白、金、青）加一个血红，没有蓝紫。各部分的做法：
  - 试管是逐像素「着色器」，按局部坐标判材质（锂肝素青盖、条码标签、玻璃高光、半月面、三层液体），从特写到 10px 宽进转子孔都清晰；
  - 离心机按 3/4 俯视投影：圆盖按铰链角度投影，所以开盖、关盖每一帧都算得出来；转子按子帧平均做运动模糊，再抖动回色板；面板有液晶转速、进度条、RUN 灯、START/STOP/OPEN 键；
  - 管内视图的红细胞：Evans–Fung 双凹盘点云 z-buffer 打光后量化成精灵，会翻滚；
  - 沉降是共同位移 D(t) 的闭式公式加六角堆积槽位：血浆前沿从上往下走，压积层从下往上长，两者在 45% 处相遇，白细胞最后落成一条淡黄白层；任意一帧可以单独渲，结果确定。
  配乐和音效全部在 `engine/audio.py` 用代码合成，没有用采样：
  - 音色：PolyBLEP 方波、NES 4-bit 三角波、NES LFSR 噪声鼓，加 SNES 式回声和 FM 铃；
  - 和声与动机：120 BPM，C 大调，IV–V–iii–vi「王道进行」，记忆动机 A5 C6 A5 G5 A5 | B5 D6 B5 A5 B5 出现四次，结尾是 ♭VI–♭VII–I 号角；
  - 和画面同步：音乐随转子刹车做磁带停转（tape stop），落在细胞堆积上的「叮」量化到十六分音符、用五声音阶。
