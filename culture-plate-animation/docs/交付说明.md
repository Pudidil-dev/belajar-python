## 制作说明（制作者填写；只写在这一段，事实段不要动）

- 交付范围：可编辑工程（代码、渲染配置 `render.json`、原创音频 `assets/audio/`、README 里的安装、预览、渲染命令）和 1080×1920 成片。成片写到 `out/culture-plate-animation.mp4`（相对本工程目录），不进仓库，`python render.py` 一条命令可以重出。
  - 客户需求（原文英文）：2D 8-bit RPG 风像素动画，俯视，干净的实验室；无字幕、无旁白；平滑循环；简单好听的音效和复古游戏配乐。剧情：俯视培养皿 → 白色棉签划出之字形 → 镜头推进到划线上一个点 → 琼脂表面上的细菌 → 细菌分裂、增殖 → 拉回培养皿 → 白色菌落沿之字形长出 → 平滑转到下一个培养皿，循环。
  - 第二版（客户追加）：「best pixel u can see the blood centrifuge style cause that video get more engagement」，即画面改成 blood-centrifuge 那支（互动最好的一支）的像素风格。第一版是浅色青灰桌面上的平涂 8-bit 画法；第二版整片重画成那支片的 16-bit 画法：同一套 `ink` 色板（炭黑、暖白、金、青、青灰玻璃）、5–9 色色阶加 Bayer 有序抖动、1px 深色描边、硬边粒子（星光、爆散、环形波、金色光束）、深色舞台上一圈灯光，主体发亮。剧情、时间、配乐和音效不变。
  - 规格：1080×1920，H.264，yuv420p，30fps，30.0 秒（120 BPM，15 小节，一拍正好 15 帧），48kHz 立体声 AAC 256k，约 8.9 MB；4 核约 40 秒渲完（首次另需约 10 秒建细菌模拟缓存）。
  - 音频：整片 −14.1 LUFS，真峰 −1.07 dBTP，样本峰值 −1.6 dBFS；整段按循环首尾相接做限幅，尾音折回开头。
- 用了哪个语法 / 风格：没用 JS 引擎和参数化片段，是自写的 Python 像素管线（numpy + Pillow + ffmpeg），`gfx`、合成器核心沿用前几支，`fx`（星光、爆散、环形波、光束、辉光）直接取自 blood-centrifuge，色板同那支片。
  - 画风：16-bit 像素游戏（SNES 时代），270×480 画布 4 倍最近邻放大；世界按镜头比例逐像素重画（推镜看到新细节，不是把像素放大）。深色环氧实验台、灯光光池、点阵、漂浮灰尘；培养皿玻璃两侧边缘高光；琼脂淡黄，靠皿壁处深琥珀，抖动渐变；棉签白色，杆按圆柱打光；菌落是暖白小圆顶，带高光点、描边和投影。
  - 之字形：6 笔，每笔一个附点四分音符，转角圆滑；预先算好每 0.08 mm 棉签经过的时刻，湿痕正好跟在棉签后面。
  - 菌落：约 850 个沿路径的软凸起相加（metaball），近的融成一条光滑的脊，远的保持圆点：起笔处是连续的白线，第五笔渐稀，最后一笔是一颗颗独立菌落（划线法的目的）。
  - 细菌特写：三个小物理模拟（杆菌生长、首尾分裂、互相推开并转动），约 50 个「创始菌」沿划线复用它们（旋转、镜像、错开时间），所以能长成一大片；每次分裂都记录时间和位置，用于爆点画面和「啵」声。镜头透过一个金属镜筒的圆镜看，周围的台面暗下来，下方金色进度条每轮分裂亮一格。
  - 镜头：划线时镜头跟着棉签略推近，划完拉回看全貌；光标锁定后快推钻进镜头；每轮分裂后退一步；镜头收回、拉远到全盘；延时时缓推，揭晓时弹回；最后两个培养皿横移交接，新皿停住即第一帧。
  - 音乐：C 大调 120 BPM，15 小节：划线段主题 A（I–vi–IV–V），俯冲段鼓退出、上行，特写段八音盒加拨弦低音（分裂的「啵」是打击乐，按和弦取音），堆积段渐强，拉出段释放，延时段四拍底鼓加十六分镲（钟声），揭晓段短号角，最后一小节通鼓过门回到开头。
  - 音效：玻璃叮、棉签呼声与落点轻敲、6 下跟着棉签左右声像的软擦声、抬起的轻响、湿痕闪光的小铃串、光标两声提示与确认、俯冲呼声、镜头开合、伸长声和第一次分裂的大「啵」、后续只给画面里看得见的分裂发声（太多时变成细碎的「嘶嘶」）、闹钟弹入、滴答、响铃、菌落长出的上行小音、揭晓铃串、星光叮、培养皿滑走的呼声、新皿落定的轻响（正好在循环点）。
- 交付前检查里发现并修好的问题：
  1. 门禁第一次跑在第一版上只有黄灯边缘（快动帧 0.036）：浅色桌面和淡黄琼脂几乎同亮度，镜头怎么动灰度差都很小。加了跟拍棉签、延时缓推和揭晓弹回、加快横移后到 0.100；第二版换成深色台面，主体和背景亮度差拉开，到 0.173，各报告项全绿。

  3. 远景菌落第一版是棕色毛糙的一团，不像白色菌落；远景时把细胞间隙填满、描边改浅，读成白色小丘。
  4. 噪声函数在坐标 0 处有接缝（负坐标取模时相邻格不连续），特写琼脂上出现一条横线；修正哈希取模顺序。
  5. 分裂的两个子细胞第一版几乎不分开；加了 0.2 秒的弹开，配合环形波和轻微震屏。

  8. 并行渲染首次运行时 4 个进程会同时写模拟缓存；改成主进程先建缓存、文件先写临时名再原子替换。
