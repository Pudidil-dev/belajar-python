# 经验回流（草稿）：How CRISPR-Cas9 Edits DNA

给 skill 维护者看的候选条目，没有改动 skill 本身。

1. **竖屏 9:16 画分子，就让分子沿屏幕竖着走。**
   - 第一版 DNA 沿 x 轴横着画，竖屏里只占中间一条窄带，上下大片空。
   - 把相机默认旋转 90°（分子轴 → 屏幕纵向），同一份几何立刻填满竖屏，螺旋的起伏也更好看。
2. **「3D 复杂模型」在 8-bit 里的解法：残基小球堆成分子表面，再按深度排序。**
   - 客户给了一张 Cas9 分子表面的 3D 参考图。用 529 颗小球按结构域填体积、靠表面更密，逐球画成扁平 8-bit 圆珠（亮面、暗面、1px 暗边），轮廓就有了沟壑和疙瘩，缩放到任何倍数都清晰。
   - 关键是**把被包裹的东西画在前后半球之间**：`half='back'` → 画 DNA 和 RNA → `half='front'`，分子就真的从蛋白的沟里穿过去，而不是贴在上面。
3. **要看清被蛋白挡住的动作时，让前半球淡出，而不是整体半透明。** 切割瞬间把 `front` 的 alpha 降到 0.15，后半球和结构域仍在，既看得见断口又没有丢失体积感。
4. **循环片的背景不能按世界坐标锚定。**
   - 片尾镜头沿分子飞了 62 个碱基对（204 Å）去下一个靶点，背景视差层按世界坐标走，于是首尾两帧的背景完全不同，接缝差 2.82（相邻帧只有 0.1–0.3）。
   - 改法：背景另给一台「布景相机」，在最后两秒插值回片头那一帧的相机参数。观众看不出来（背景本来就是布景），接缝降到 0.196，比普通相邻帧还小。
5. **序列按周期平铺，循环就能落在「同一个靶点」上。** 让 `seq_at(i)` 对 62 取模，片尾飞到 `PAM_I + 62`，再给螺旋相位补上 `-2π·62/TURN`，首尾两帧的局部画面逐像素同构。
6. **已修复的缺失要锚在真正的接口上。** 片尾用 `del_` 画「短了 2 bp 的分子」时，一开始把缺口索引跟着新靶点平移，结果新靶点旁边凭空多了一个折角。改成缺口永远在真实接口（CUT_I），视野里整体平移即可抵消。
7. **音效被盖住时，先问能不能给音乐留个洞。** 「找错位点」的闷音是故意要闷的，调大就不闷了；改成在那半拍把旋律去掉（`continue`），它就自己出来了，比抬增益好。
8. **科学细节值得在代码里验一遍。** PAM 一开始写错（非靶链不是 NGG），是在终端打印两条链和向导 RNA 的序列时发现的；顺带把「诱饵 PAM」做成真 PAM 但原间隔序列 19/20 不匹配，才站得住。
