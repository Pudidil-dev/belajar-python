# 交付说明：crispr-cas9-animation（可编辑工程，未导出成片）

## 交付范围

客户要求「Create the editable animation project and assets only. Do not render the final MP4.」，所以本次交付的是**可编辑工程和素材**，没有 `out/*.mp4`：

- 代码工程 `engine/`（时间轴、调色板、像素工具、DNA、Cas9、修复蛋白、细胞核背景、特效、标签、分镜合成、音频）
- 渲染入口 `render.py` 和渲染配置 `render.json`
- 原创音频 `assets/audio/`（`music.wav`、`sfx.wav`、`mix.wav`，48 kHz 16-bit 立体声，正好 22.0 秒）
- 镜头表 `镜头表.md`、分镜图 `docs/storyboard.png`、README（含逐条渲染命令）

客户自己渲染成片：在本目录下 `pip install -r requirements.txt` 后 `python render.py`，写到 `out/crispr-cas9-animation.mp4`（1080×1920，30fps，H.264 + 48kHz 立体声 AAC，22.0 秒），4 核约 1 分钟；`python render.py --preview` 出 540×960 快览。全部命令见 README「Render it yourself」。

## 规格

- 1080×1920（9:16 竖屏），30 fps，22.0 秒 = 120 BPM × 11 小节，一拍正好 15 帧，所有音画事件都落在格子上
- 270×480 画布 4 倍最近邻放大；无旁白、无字幕；屏上字是 18 条**跟随物体的小标注**加 1 个小横幅（DNA EDITED）
- 音频：整片 −14.03 LUFS，真峰 −1.27 dBTP，按循环首尾相接做限幅

- 黄灯项说明：片长只有 22 秒，剧情本身是「远—近—远」的三次景别切换（0–3 秒冲进切口、8–10 秒推到切割结构域、18–20 秒拉开看前后对比），折算成每分钟就偏高。每次推近之后都有拉远或横移还回来（3.6 秒拉开成梯子、12–13 秒拉远、20–22 秒横移到下一个靶点），没有连续三镜往里推，也没有 0.5 秒以内的急推。

- 确定性：同一时刻渲两次逐像素一致。
- 音效对位：22 个事件逐个按频段与同时刻音乐比较，每个都在其两个最强频段之一高出音乐 ≥4 dB；「找错位点」的闷音不是靠调大，而是在旋律里给它留了一个空拍。

## 本轮修改：跟随物体的说明性标注（客户追加）

客户要求「saya butuh beberapa clean caption tracking object untuk penjelasan nya」和「perlihatkan kode genetik kecil kecil di caption dna sebagai bentuk perubahan dna」，于是把原来的 4 条小标注扩成一套会跟着物体走的说明标注：

- **跟随**：锚点每一帧从物体本身算出来（Cas9 的 REC 叶、两个切割结构域各自的当前位置、配对到第几个碱基、断口、修复环、幽灵链），所以标注会跟着滑动、摆动、分开的 DNA 一起走。
- **干净**：深色底板加 1px 描边，所以压在蛋白表面上也读得清；肘形引线加物体上的小圆点；自动选左右（哪边放得下放哪边），并夹在手机安全区内（上 64px、下 112px 不放字）；同屏最多两条；逐字打出。
- **把密码写进标注**（本轮重点）：
  - 开头 `DNA · ATCCGG`：镜头正对着的那 6 个碱基，直接取自序列。
  - 找到位点时 `PAM · CGG`：真实读出的 PAM 三个碱基。
  - 结尾对照 `BEFORE · CC**GG**AGG`（要被切掉的两个碱基标红）对 `AFTER · CCAGG`，一眼看出少了哪两个——这就是「DNA 改变」的具体样子。
- **碱基字母**（客户再追加：「di ujung dna boleh kasih huruf dari dna agct」）：镜头够近时，每个碱基珠变成一块扁平的浅色方砖，带同色深边，上面盖一个 3×5 的字母（DNA 是 A/G/C/T，向导 RNA 是 A/G/C/U）。阈值按珠子半径定（≥3.9 px）：切割（5.0 px/Å）、慢动作、修复（4.0 px/Å）和钩子冲进切口时有字母；搜索段（3.45 px/Å）和片尾前后对比（2.24 px/Å）保持实心珠子——那个尺寸的字母只会糊成一团，前后对比由标注里的序列负责。修复段相机从 3.3 微调到 3.5 px/Å，就是为了让字母在那一段也读得出来。
- 全部标注（按时间）：DNA·ATCCGG、CUT!、CAS9、GUIDE RNA、NO MATCH、PAM·CGG、MATCHING、LOCKED、HNH、RUVC、CUT BOTH STRANDS、CAS9 LEAVES、REPAIR、LOST 2 PAIRS、SEALED、BEFORE·CCGGAGG、AFTER·CCAGG、NEXT TARGET，外加 DNA EDITED 横幅。
- 镜头表 lint 曾对第 1 镜报黄（开场 3 秒里出现 4 个词），已把开场的 CAS9 标注删掉（它在第 2 镜有足够时间出现），现在全表绿灯。
- 加标注后重跑门禁：快速运动帧占比 0.301，空画面 0 秒，蓝紫 0.000，**固定页框 0.000**（标注跟着物体动，没有被判成常驻页框）；循环接缝 0.196，仍小于普通相邻帧。

## 制作说明

- 客户需求：22 秒 2D 8-bit RPG 像素风科普动画，竖屏 9:16，深海军蓝底、明亮 DNA 与分子精灵；无旁白/字幕/大字，只有必要的小标注；流畅推拉、干净转场、令人满意的像素特效；原创上头的 chiptune 和同步街机音效；五场戏：钩子（切 DNA）→ Cas9 怎么找到靶点 → 分子剪刀 → DNA 修复 → 结果与循环。
- 客户追加四条：
  1. 「agar lebih hidup videonya buat latar dari dna memperlihatkan dna lain atau cell atau apapun itu agar ada lebih ada kesan world building nya」→ 加了细胞核世界：三层视差（远处染色质环、其它 DNA 双螺旋、核质里的核小体与游离蛋白），按世界坐标平铺，镜头推拉时层次分明，每层漂移都是每循环整数圈。
  2. 「use model blood centrifuge refference as a model 8bit 2d pixel」→ 整片改用本仓库 blood-centrifuge 那支片的 `ink` 色板与画法（炭黑底、暖白、金、青、血红），短色阶 + Bayer 有序抖动 + 1px 深色描边 + 硬边粒子，特效模块 `fx.py` 直接取自那支片。
  3. 「revisi bentuk CRISPR dengan model 3d complex 8bit dengan banyak abstraksi di dalamnya seperi gambar refference」（附 Cas9 3D 分子表面参考图）→ Cas9 重做成**分子表面**：529 颗残基小球按结构域堆成，按深度排序、左上打光，轮廓疙疙瘩瘩有沟壑；DNA 和向导 RNA 画在蛋白的「后半球」和「前半球」之间，所以真的是从沟里穿过去；结构域分色（PI 金、HNH 血红、RuvC 青）。
  4. 「clean caption tracking object」+「把基因密码写进 DNA 标注」→ 见上一节。
- 科学口径与简化：见 README「The science (as drawn)」。关键的一条按客户要求守住了：**Cas9 不会把 DNA 改写成想要的序列**，片中只展示一种代表性结局（丢掉 2 个碱基对的小缺失），修复由细胞完成，结果不保证。
- 画风与音乐：见 README「How it is made」。
- 「六种做坏方式」逐条自查：
  1. 翻页式 PPT：无页眉页码、无片名卡；镜头跟着事件走（快推、倒带、横移跟拍、缓推、慢动作、拉远、横移），没有每镜同一个动作；固定页框 0.000。
  2. 照搬示范：没有。画法和特效取自本仓库自己的 blood-centrifuge（客户点名），构图按题材重新设计。
  3. 没有具体的物：从头到尾是同一条 DNA、同一个 Cas9、同一段修复。
  4. 死背景、空画面：中段空画面 0 秒；细胞核三层视差一直在动；死背景 0.023。
  5. 有真实素材却用代码去画：客户只给了一张 Cas9 3D 参考图用于造型，没有可直接满幅使用的素材，题材指定像素风。
  6. 一眼 AI 味：蓝紫底 0.000（海军蓝色相约 214°，避开 225–300°）；同一套 ink 色板贯穿；没有人物、没有脸。
- 没派独立审片（没有另一个人或 agent 看过），客户可以渲一遍自己看。
